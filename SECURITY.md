# Security Policy

## Supported version

Security fixes are considered for the latest 0.1.x release.

## Reporting

Use GitHub's **Report a vulnerability** private vulnerability-reporting feature for sensitive reports. Do not open a public issue containing exploit details or personal data. Open a normal issue for non-sensitive defects.

This is fictional educational simulation software, not operational economic or financial software. Do not use its output for financial, forecasting, policy, or operational decisions.
