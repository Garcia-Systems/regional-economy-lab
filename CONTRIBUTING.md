# Contributing

Thank you for improving this small educational project. Open an issue before a large change; v0.1.x is limited to Chapters 0–2 and the existing one-month systems.

1. Use Python 3.13 and install `python -m pip install -e '.[dev]'`.
2. Keep money as integer cents, rates as `Decimal`, outputs deterministic, and assumptions fictional and explicit.
3. Run `ruff check .`, `pytest`, and `python scripts/verify_release.py`.
4. Update tests and learner documentation with behavior changes.
5. Submit a focused pull request using the repository template.

Reports of conduct issues may be made through GitHub repository-owner contact tools. By participating, you agree to the Code of Conduct.
