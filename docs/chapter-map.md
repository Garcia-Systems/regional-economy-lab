## Shared chapter contract

Every chapter uses its named executable, an Explain or Trace walkthrough, a small controlled experiment, answerable interpretation questions, explicit assumptions and limitations, a concise summary, and the safe debugging contract. The debugging contract is: **Goal → Launch Configuration → Scenario → Breakpoint → Objects to Inspect → Expected Fault → Reconciliation or Indicator Effect → Fix → Economic Meaning → Verification**. Optional connections to other Garcia Systems laboratories are conceptual only and are neither links nor runtime dependencies because no verified repository URLs are maintained here.
