# Data Sources

Version 0.1.0 uses **only fictional and assumed educational values**. Geographic names are
public-data placeholders; they do not make the numeric values Williamsburg statistics.

## Template for a future public dataset

- **Source:** stable title and URL
- **Publisher:** responsible institution
- **Publication date:** date or release vintage
- **Geographic coverage:** boundaries and identifiers
- **Units:** dollars, people, establishments, or other unit
- **Transformations:** inflation adjustment, aggregation, imputation, and rounding
- **Limitations:** uncertainty, suppression, coverage gaps, and comparability
- **License or usage notes:** license, attribution, redistribution, and access date
